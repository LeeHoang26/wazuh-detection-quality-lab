# Lab limitations

- The offline matcher is a small Python model of field-level rule logic. It is not a Wazuh decoder or Manager.
- The corpus has 17 hand-picked cases. It cannot represent all Windows and Active Directory activity.
- The shortcut exclusion covers only the filename and Recent-items path described in the [case study](canary-shortcut-case-study.md). That candidate has not been validated on a Wazuh Manager. It does not imply that every shortcut or Explorer process is benign.
- Precision and recall in the reports describe this lab corpus, not production detection performance.
- Wazuh may decode fields differently from the offline model. Use `wazuh-logtest` and live EventChannel validation to check actual rule behavior.
- A JSON fixture pasted into Ruleset Test reaches the `json` decoder. The Windows rule expects `windows_eventchannel`, so Phase 2 decoding alone is not evidence of a missed rule match.
- Historical alerts in Discover show that a rule fired before. They are not actual results for a similar fixture. Do not fill in `reports/actual/` unless that exact event passed through the Windows Agent.
- On 2026-10-02, rule `100100` was observed on the Manager at level 8. The baseline file in this repository is an earlier level-12 snapshot. They are not the same deployed version.
- Initially, rule `100200` was absent from the Manager even though `ossec.conf` had an Active Response entry for `canary-triage.cmd`. A detection-only candidate was later loaded for live validation, with Active Response disabled. The handler can suspend and terminate the process identified from Sysmon Event 11, so it was not enabled for this test.
- The live detection-only candidate matched a real TXT Event 11 generated by an Explorer file copy. This verifies telemetry delivery and rule coverage, not ransomware activity or the safety of an automated response.
- This repository does not send Telegram messages, disable accounts, block IPs, terminate processes, or isolate hosts.
- Action names in fixtures are response discussion labels, not executed commands.
- Edge cases are reported separately from precision and recall because they test context and safety decisions.
- Copy rules to a Wazuh Manager only in an isolated lab, and check for rule ID collisions before restarting it.
- Do not commit actual results from a personal environment if they contain usernames, internal IP addresses, or other sensitive data.
